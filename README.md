# Mahjong

Mahjong is a tile-matching game that uses a set of 144 tiles based on Chinese characters and symbols. The goal of the game is to remove all the tiles from the board by matching pairs of identical tiles.

## Features

- Tile matching and removal
- Board visibility management
- Tile hover information display
- Shuffle and reset functionality


### Controls
Left Click: Select a tile
Right Click: Deselect a tile
F2: Reset
F10: Shuffle
